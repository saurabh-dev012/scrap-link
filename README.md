# Kabadiwala Connect — Smart India Hackathon (SIH) 2026

> **Tagline:** “Bringing the informal collector into the formal recycling chain.”

**Kabadiwala Connect** is a modern, production-grade full-stack web application designed for **Smart India Hackathon 2026**. It provides an end-to-end digital infrastructure linking households, informal waste pickers (*kabadiwalas*), municipal material recovery facilities (MRFs), and verified industrial recyclers onto a unified, transparent, and verifiable ledger.

---

## 🚀 Live Demo & Getting Started

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build
```

Local dev server runs at: `http://localhost:5173/`

## 🏛️ Core Features

1. **Custom Production-Grade Design System**:
   - Palette: Deep Forest & Cyber Emerald (`#047857`, `#10b981`), Crisp Teal (`#0d9488`), Tech Slate (`#0f172a`), Clean Card White (`#ffffff`), and Civic Indigo (`#4338ca`).
   - High-contrast badges, glassmorphic cards, micro-interactions, responsive grids.

2. **Unified 4-Role Architecture**:
   - **Household**: Multi-material booking, live scrap valuation, nearby radar collector match.
   - **Collector (Kabadiwala Partner)**: Vernacular-friendly app, IoT calibrated digital scale simulator, doorstep PIN verification, instant UPI Jan-Dhan payout.
   - **Verified Recycler**: Batch intake queue, purity inspection, and official CPCB EPR credit issuance.
   - **Municipal Admin (ULB)**: Collector KYC onboarding queue (e-Shram & Aadhaar), CPCB recycler registry, ward-wise recycling diversion tracking.

3. **End-to-End Cryptographic Waste Traceability (USP)**:
   - Searchable Waste IDs (`KC-2026-004821`, `KC-2026-008314`, `KC-2026-009142`, etc.)
   - 5-stage chronological audit timeline with GPS logs, actor signatures, and SHA-256 tamper-evident hash digests.
   - Dynamic QR code generation and printable **CPCB EPR Green Certificate of Recycling**.

4. **Collector Dignity & Digital Identity (`KC-COL-004821`)**:
   - Formalized digital identity cards linked with **e-Shram** UAN and **Ayushman Bharat** health insurance.
   - Printable **Certificate of Formal Green Accreditation**.

5. **Live Mandi Scrap Pricing & Calculator**:
   - Real-time rates for Paper, PET Plastic, Hard Plastic, Cardboard, Iron, Copper, Aluminium, and E-Waste with trend indicators.
   - Multi-item interactive scrap value estimator.

6. **Impact & Municipal Sustainability Dashboard**:
   - Animated KPI counters (Kg recovered, collectors connected, CO₂ avoided, informal earnings paid, trees preserved).
   - Recharts visual analytics: Monthly recovery trends, category distribution donut, direct collector payouts, ward diversion rates.

7. **SIH 2026 Judge Demo Flow (3–5 Minute Tour)**:
   - Interactive floating controller at bottom-right allowing judges to step through the entire circular lifecycle with a single click.
