# Kabadiwala Connect

Kabadiwala Connect is a modern circular-economy platform designed to connect households, informal waste collectors, verified recyclers, and municipal administrators through a transparent traceability system for waste recovery and material flow.

Built for Smart India Hackathon 2026, the application demonstrates how digital identity, scrap pricing, and tamper-evident waste tracking can formalize the informal recycling ecosystem.

## Why this project matters

India’s waste collection ecosystem is highly fragmented. Informal collectors often work without formal identity, consistent pricing, or verifiable incentives. Kabadiwala Connect addresses that gap by creating a digital layer that enables:

- transparent scrap valuation
- traceable material movement
- formal collector recognition
- recycler accountability
- city-level waste diversion visibility

## Core features

- Household booking flow for scrap pickup and material scheduling
- Collector dashboard with digital identity and payout workflows
- Recycler intake and quality verification flows
- Admin monitoring for ward-level recycling performance
- Live scrap price calculator with material categories
- Traceability timeline with waste IDs and tamper-proof hash-style representations
- Impact dashboards with recovery, emissions, and earnings analytics
- Responsive, animated UI built with React, Vite, Tailwind, and Framer Motion

## Getting started

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

The app runs locally at http://localhost:5173
